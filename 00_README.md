# Интерактивная карта мест заключения священнослужителей СЛОН

Материалы и приложение к IT-мастерской Соловецкой школы молодых учёных «Окоём»,
24.08–31.08.2026. Собрано 21.08.2026, накануне выезда.

## Быстрый старт

```
open ~/okoyom/app/index.html     # посмотреть приложение
code ~/okoyom                    # открыть проект в редакторе
```

`~/okoyom` — короткая ссылка на эту папку: настоящий путь лежит в iCloud и состоит
из пробелов и кириллицы.

## Что уже сделано

**Приложение работает.** Открывается по `file://` без сервера и без интернета, 9,9 МБ.

- карта архипелага **и материкового берега у Кеми** из данных OpenStreetMap:
  749 контуров суши, 540 озёр, масштаб до 24×, панорама, щипок;
- метки цветом и значком по типу места, группировка близких точек с распадом при зуме,
  автораскладка подписей по четырём позициям, легенда;
- реестр всех **411 персоналий**: поиск, фильтры по сану и месту;
- карточки людей и мест: биография, источник, несколько фотографий с подписями
  авторства, просмотр во весь экран;
- словарь терминов, экран покоя с возвратом через 90 секунд;
- тёмная и светлая темы;
- **панель музея**: сотрудник правит персоналии, места, вид меток и фотографии
  прямо в приложении и сохраняет кнопкой, без терминала.

## Устройство приложения

```
app/
├── index.html              разметка
├── css/style.css           вся палитра и отступы в :root
├── js/app.js               весь код, один файл
├── assets/
│   ├── map-base.svg        подложка, светлый вариант рядом
│   ├── icons.js            34 значка Tabler Icons (MIT)
│   ├── photos/  places/    фотографии по имени <id>.jpg
└── data/
    ├── build.py            сборка data.js из таблиц
    ├── make_map.py         OSM → карта, пересчёт координат меток
    ├── make_icons.py       пополнение набора значков (нужна сеть)
    ├── persons.csv         411 персоналий — ИСТОЧНИК ПРАВДЫ
    ├── places.csv          16 мест
    ├── types.csv           цвет и значок по типу места
    ├── photo-credits.csv   авторство и лицензии снимков
    └── data.js             всё вместе, читает приложение
```

Пересборка после правки таблиц:

```
cd ~/okoyom/app/data && python3 build.py
```

## Если вы клонировали репозиторий

`persons.csv` и `data.js` в репозитории намеренно отсутствуют — это данные музея,
см. [app/data/ЧЕГО_ЗДЕСЬ_НЕТ.md](app/data/ЧЕГО_ЗДЕСЬ_НЕТ.md). Чтобы приложение заработало,
положите `Spisok_po_mestam_3.xlsx` рядом с папкой `app` и выполните:

```
cd app/data && python3 build.py --import
```

## Четыре вещи, которые надо помнить

1. **Защита 31 августа, 10:00–14:00** — не 2 сентября. Проектной работы ≈26 часов,
   из них 28 и 29 августа — ноль.
2. **Интернета не будет.** Ни `npm install`, ни шрифтов из сети, ни API значков.
   Всё скачано заранее; чек-лист — в конце `05`.
3. **70 % персоналий не привязаны к месту.** Карта одна закроет 30 % материала,
   поэтому «карта + реестр» равноправны.
4. **Четыре раздела брифа заказчик не заполнил.** Чек-лист вопросов на первую
   встречу с А. П. Яковлевой — в `06`.
