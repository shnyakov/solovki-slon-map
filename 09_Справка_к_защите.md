## 3. Технологический стек

Главное, что стоит сказать: стек выбран не по вкусу, а одним ограничением —
**на Соловках нет интернета**, приложение живёт файлом и должно работать
после того, как мы уедем.

| Слой | Чем сделано | Объём | Почему так |
|---|---|---|---|
| Интерфейс | HTML, CSS, чистый JavaScript | 4 495 строк | Ни фреймворка, ни сборки, ни `node_modules`. Любая зависимость — это либо запрос в сеть, либо папка, которую в музее некому обновлять |
| Данные | CSV → Python → `data.js` | 434 записи | Музей открывает CSV в Excel, git показывает построчную разницу. Никакой базы, которую надо поднимать |
| Подключение данных | тег `<script>`, не `fetch` | — | По протоколу `file://` браузер режет `fetch()` и модули из-за CORS. Тег — единственное, что там работает без сервера |
| Карта | OpenStreetMap → Python → статичный SVG | 324 КБ | Тайловая карта — это сеть. Здесь один векторный файл, чёткий на любом увеличении |
| Спутниковый слой | Sentinel-2 cloudless (EOX), CC BY 4.0 | 0,8 МБ | Кнопкой, не по умолчанию: снимок показывает сегодняшние Соловки, а экспозиция про 1923–1939 |
| Шрифты | PT Sans и Pobeda, лежат в проекте | 136 КБ | Те же, что на сайте музея. Свой файл вместо системного: киоск в зале — машина неизвестная |
| Значки | Tabler Icons, вшиты в файл | 34 шт. | Скачаны заранее, лицензия MIT |
| Сохранение | File System Access API | — | Chrome и Edge пишут прямо в папку. Для Safari и Firefox — локальный сервер на стандартном Python |
| Скрипты сборки и проверки | Python, стандартная библиотека | 3 229 строк | Единственное исключение — `openpyxl` для чтения Excel музея, и он нужен только при импорте |
| Проверки | headless Chrome + Python | 144 проверки | Слои карты накладываются друг на друга, и ошибки в них тихие. Каждое нажатие адресуется через `elementFromPoint` — тому, что реально лежит под курсором |

**Инфраструктура нулевая:** ни сервера, ни хостинга, ни лицензий, ни подписок.
Флешка с папкой.

## 6. Тезисы для слайдов

Готовые формулировки. Каждая опирается на измеренный факт — это то,
что отличает защиту от пересказа.

### Архитектура

**Ограничение определило стек, а не наоборот.** На Соловках нет интернета.
Отсюда ноль зависимостей, данные через тег вместо `fetch`, карта одним SVG
вместо тайлов, шрифты в проекте. Приложение открывается двойным щелчком
и не обращается в сеть ни разу.

### Данные

**Рост со 125 привязок до 165 дал разбор структуры, а не объём.**
В новой таблице сан стоит один раз на группу, а не в каждой строке; мирская
фамилия монашествующего записана в скобках. Прежний код брал из группы только
первого и терял всех, у кого фамилия в скобках, — из алфавитного списка
не находилось 73 строки. После разбора осталось 9 неразличимых однофамильцев,
и это уже вопрос к источнику, а не к программе.

### Проверяемость

**144 автоматические проверки, и они находят настоящие поломки.**
Перетаскивание вершин зон было сломано до нас и молча: обработчик висел
на соседнем слое, и вершина отклеивалась от курсора через тринадцать пикселей.
Проверка нашла и это, и то, что два сохранения в одну секунду затирали
снимок истории.

Два последних стенда меряют не результат, а время: пересобрался ли слой
меток посреди щипка, ехала ли высота снимка или прыгнула. Жалобу «метки
скачут при приближении» закрыла не подкрутка анимации, а правило
«пока карта движется, группы не пересобираются» — и теперь это правило
проверяется само.

### Честность данных

**Приложение показывает, чего в данных нет.** 269 человек из 434 без места,
ни у одного из 13 мест нет исторической справки. Отчёт о полноте называет это прямо.
Учёт музея сверяется с расписанным по фамилиям: 12 мест сходятся точь-в-точь,
4 расходятся — и разница указывает ровно на те записи, которых не хватает.

### Передача музею

**Данные правятся без нас.** Сотрудник открывает `index.html#edit`, правит,
нажимает «Сохранить», обновляет страницу. Перед каждой записью делается снимок,
хранятся тридцать последних, откат в одно нажатие. Ни командной строки,
ни копирования файлов.

Вход намеренно один. Удержание заголовка и `Cmd+E` убраны: в зале посетитель
мог продержать палец на названии две секунды и попасть в панель правки данных.

### Стиль музея

**Связь с экспозицией не декларативная, а измеренная.** Шрифты взяты с сайта
музея: PT Sans в тексте, Pobeda в заголовке — ровно как у них. Палитра карты —
белая земля на сланцевом море, как на их карте-схеме. Их собственный синий
пробовали взять целиком, но на нём пропадают подписи мест, поэтому тон светлее.

## 8. Чего в проекте нет — и это нужно сказать

Слабые места лучше назвать первыми, до вопроса из зала. Каждое —
вместе с тем, что с ним делать.

- **Историческая справка не написана ни для одного места.** Поле готово,
  тексты нужны от музея. До тех пор блок в карточке просто не показывается.
- **Зоны работ не размечены.** Механизм построен и проверен, данных нет:
  обводить зоны по растровой карте на глаз — значит выдумать геометрию.
  Заказчик снял задачу.
- **Портретов 17 на 434 человека.** Музей пришлёт свои позже; восемь взяты
  из базы фонда, и только там, где личность совпала и по имени, и по фамилии,
  и кандидат был один.
- **Вертикальный экран не проверен вживую.** Режим есть и работает в браузере,
  но на настоящем киоске его не видели.
- **Сохранение в Safari и Firefox только через локальный сервер.**
  Это граница безопасности браузера, обойти её из страницы нельзя.
