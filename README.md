# Интерактивная карта мест заключения священнослужителей СЛОН

Приложение к экспозиции «Соловки. Испытание веры. Век ХХ» (зал № 2)
Соловецкого музея-заповедника. Показывает, где в соловецких лагерях
находились и работали священнослужители, и даёт сведения по каждому человеку
из списочного состава — в том числе по тем, чьё место неизвестно.

Сделано в IT-мастерской Соловецкой школы молодых учёных «Окоём», 24–31.08.2026.
Постановка задачи — А. П. Яковлева, заведующая отделом истории Соловецкого
архипелага.

## Как открыть

```
open app/index.html
```

Всё. Ни сервера, ни сборки, ни установки зависимостей, ни интернета:
приложение открывается двойным щелчком и работает по протоколу `file://`.

Чтобы отдать приложение человеку, который в этом не разбирается:

```
python3 app/data/make_release.py
```

Соберётся `release/Соловки-карта.zip` — 26 МБ. Распаковать целиком, нажать
на «ОТКРЫТЬ КАРТУ.html». Одинаково на Windows, macOS и Linux.

Смотреть можно в любом браузере. Правка данных с записью в файлы работает
в Chrome и Edge: в Safari и Firefox у страницы просто нет нужного интерфейса
(File System Access API), для них есть локальный сервер на `app/data/server.py`.

## Данные

Сведения о персоналиях — материал **Соловецкого музея-заповедника**: рабочая
таблица «Список по местам», сведённая с алфавитным списком экспозиции.
Разбор исходной таблицы и все расхождения — в [docs/03_Данные_аудит.md](docs/03_Данные_аудит.md)
и [docs/08_Аудит_новых_данных.md](docs/08_Аудит_новых_данных.md).

Что в данных **не сходится**, и это важнее, чем то, что сходится:

- **9 однофамильцев** различить нельзя: пятеро Поповых, четверо Правдолюбовых,
  трое Сахаровых. Приписать человека к чужому месту хуже, чем оставить без места;
- **12 человек** есть на листах мест, но отсутствуют в алфавитном списке;
- у **7 записей** сан «арх.» — архимандрит или архиепископ, по таблице не понять;
- **историческая справка не написана ни для одного места**: поле есть, тексты
  нужны от музея, они напечатаны на планшетах зала;
- **английские имена** — машинная транслитерация, у музея могут быть свои формы
  имён новомучеников. Переключатель языка пока скрыт.

В репозиторий намеренно **не** попадает `app/data/to-check-places.csv` —
рабочий файл с неподтверждёнными догадками о том, кто где содержался.
Публиковать предположения о конкретных людях нельзя, см.
[app/data/ЧЕГО_ЗДЕСЬ_НЕТ.md](app/data/ЧЕГО_ЗДЕСЬ_НЕТ.md).

Ссылаться на сведения следует на музей как на источник, а не на этот репозиторий.

    ├── make_map.py         OSM → карта, пересчёт координат меток
    ├── make_satellite.py   Sentinel-2 → слой в той же проекции
    ├── make_release.py     архив для передачи
    ├── server.py           сохранение для Safari и Firefox

    ├── places.csv          13 мест

Пересборка после правки таблиц и проверки:

```
cd app/data && python3 build.py
python3 app/data/test_edit.py    # 51 проверка: разметка и правка
python3 app/data/test_save.py    # 30 проверок: запись и история версий
python3 app/data/test_map.py     # 35 проверок: метки при щипке, колесе, зуме
python3 app/data/test_photo.py   # 28 проверок: смена снимка, высота, листание
```

Импорт новой таблицы музея (нужен `openpyxl` — единственная внешняя библиотека
во всём проекте, и только здесь):

```
cd app/data && python3 build.py --import
```

## Почему так, а не на фреймворке

**На Соловках нет интернета.** Ни `npm install`, ни шрифтов из сети, ни CDN,
ни тайловой карты. Всё, что не скачано заранее, недоступно — и остаётся
недоступным после того, как мы уедем.

Отсюда всё остальное: ноль зависимостей, данные подключаются тегом `<script>`,
а не `fetch` (по `file://` браузер режет `fetch` и модули из-за CORS), карта —
один векторный файл вместо тайлов, шрифты лежат в проекте. Инфраструктура
нулевая: ни сервера, ни хостинга, ни лицензий, ни подписок. Флешка с папкой.

Устройство и причины решений подробно — в [CONTEXT.md](CONTEXT.md).

## Права

**Код — под [MIT](LICENSE).** Это разметка, стили, `app/js/app.js` и скрипты
в `app/data/`: берите, правьте, используйте.

**Лицензия не распространяется на содержимое.** Оно не наше, и раздавать его
мы не вправе:

- сведения о персоналиях (`app/data/persons.csv`, `app/data/data.js`) —
  материал Соловецкого музея-заповедника;
- фотографии в `app/assets/photos/` и `app/assets/places/` — фонды музея,
  Викисклад и база «Новомученики и исповедники», условия у каждого свои,
  построчно записаны в `app/data/photo-credits.csv`;
- шрифт, значки, береговая линия и снимок из космоса — под своими лицензиями,
  перечислены выше.

Если вы берёте отсюда код — данные и снимки замените своими.
