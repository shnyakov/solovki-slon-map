# Почему нет persons.csv и data.js

Их намеренно нет в репозитории: см. `.gitignore` в корне.

В `persons.csv` — 411 имён репрессированных священнослужителей из неопубликованной
рабочей таблицы Соловецкого музея-заповедника, со ссылками на архивно-следственные
дела УФСБ. Это материал музея, и выкладывать его на сторонний сервис без ведома
заказчика неправильно, даже в приватный репозиторий.

## Как запустить приложение из чистого клона

1. Положите `Spisok_po_mestam_3.xlsx` рядом с папкой `app` (или выше по дереву).
2. Выполните:

```
cd app/data
python3 build.py --import
```

Скрипт вычитает таблицу, создаст `persons.csv` и соберёт `data.js`.
После этого `app/index.html` открывается и работает.

Остальные таблицы — `places.csv`, `types.csv`, `photo-credits.csv` — в репозитории
есть: персональных данных в них нет.
