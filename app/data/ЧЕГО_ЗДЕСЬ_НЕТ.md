# Чего в этой папке нет

`persons.csv` и `data.js` **здесь есть**: с 29.08.2026 данные публикуются
вместе с приложением. Раньше их не было — материал музея не выкладывали
на сторонний сервис.

Не выкладывается и дальше вот что.

## `to-check-places.csv`

Рабочий файл: тринадцать строк с **догадками** о том, кто где содержался.
Место в них выведено из текста записи («участок Белужье 1-е отдел. СЛАГ»,
«к-ка Секирная») и заказчиком не подтверждено.

Такие строки нельзя публиковать: предположение о конкретном репрессированном
человеке прочтут как установленный факт. Файл нужен для работы с заказчиком —
по нему задаются вопросы, а подтверждённое переносится в `persons.csv`.

## `history/`

Снимки состояния, которые приложение делает перед каждым сохранением.
Это копии тех же шести файлов, в репозитории они только шум.

## Исходники карты

`osm-coastline.json` и `osm-water.json` — 5,6 МБ выгрузки из Overpass API.
Из них уже собрана `app/assets/map-base.svg`; заново они нужны, только если
менять охват карты. Снимаются `make_map.py`, для этого нужна сеть.

## Таблица музея

`Spisok_po_mestam_3.xlsx` — исходный файл заказчика. В репозитории лежит
результат его разбора, а не он сам. Импорт новой версии:

```
cd app/data && python3 build.py --import
```
